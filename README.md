# IT Support Ticket Analysis

## Project Overview
This project analyzes IT support ticket data to understand ticket resolution efficiency, agent performance, and employee satisfaction.

## Objectives
- Analyze the overall IT support ticket volume.
- Evaluate IT agent performance.
- Analyze ticket resolution time.
- Understand employee satisfaction levels.
- Identify areas for improvement in IT support services.

## Tools & Skills Used
- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Analysis
- Dashboard Creation
- Data Analysis

## Key Analysis
- Year-wise ticket volume analysis
- Agent-wise ticket performance
- Average ticket resolution time
- Employee satisfaction analysis
- Priority and severity analysis
- Issue type and request category analysis
